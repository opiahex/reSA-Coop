# reSA-Coop

Сюжет GTA San Andreas для хоста и двух гостей. Хост загружает своё сохранение и запускает миссии; у каждого игрока остаются свои деньги, оружие, навыки и внешность. Спортзал, школы и подработки можно проходить отдельно.

[Скачать мод](https://github.com/opiahex/reSA-Coop/releases/latest) · [История изменений RU / EN](CHANGELOG.md) · [English](README.en.md)

## Что исправлено

- Дублирование и исчезновение машин при угоне, отключении игрока и переходах в интерьер.
- Запуск двигателя гостями, посадка на занятые места и вытаскивание водителя из машины.
- Цвета и варианты кузова, груз, колёса, повреждения, ремонт и вращение винтов.
- Трафик и NPC: общая зона рядом с хостом и отдельные зоны, когда игроки разъезжаются.
- Камеры, субтитры, сюжетные реплики и возврат управления после сцен.
- Миссионные предметы, огонь, изменения карты и восстановление пропавших сетевых объектов.

Есть дополнительный транспорт и места для гостей в поддерживаемых сюжетных поездках. Они появляются по условиям миссии: обычная поездка не превращается в постановочную стрельбу.

Полный список исправлений — в [CHANGELOG](CHANGELOG.md). Не все миссии и сочетания сторонних модов проверены; о найденных проблемах можно сообщить в [Issues](https://github.com/opiahex/reSA-Coop/issues).

## Установка

Нужна **GTA San Andreas 1.0 US для Windows**. Definitive Edition не поддерживается.

1. Скачайте **reSA-Coop-…-win32.zip** из [последнего релиза](https://github.com/opiahex/reSA-Coop/releases/latest).
2. Распакуйте архив целиком рядом с `gta_sa.exe`.
3. Если ASI-загрузчик ещё не установлен, запустите `install.bat`.
4. Запустите игру и нажмите **F9**.

Архив содержит `coop.asi` и папку `coop` с сервером и остальными файлами мода. Отдельный `coop.dll` для игры не нужен. Архивы **Source code** предназначены для сборки из исходников.

При обновлении сохраняйте настройки и `coop/server-data` с профилями игроков. **У всех участников и сервера должна быть одна версия мода.**

## Как подключиться

Хост открывает **F9 → Создать игру**, выбирает сохранение и передаёт гостям код. Гости вводят его через **F9 → Подключиться**. Встроенный сервер запускается автоматически; при запросе Windows разрешите ему доступ к сети.

Миссии запускает хост. Важные сюжетные маркеры ждут остальных участников, а смерть участника общей миссии приводит к её провалу. Обычные находки и личные занятия этого ожидания не требуют.

Для игры вместе используйте одинаковые сюжетные скрипты, характеристики транспорта и коллизии моделей.

## Если что-то сломалось

В [отчёте об ошибке](https://github.com/opiahex/reSA-Coop/issues) укажите версию, название миссии и действия перед сбоем. Для рассинхронизации нужны логи участников за один сеанс:

- `coop/coop.log`;
- `coop/crash.log`, если был вылет;
- соответствующие файлы из `coop/diagnostics`.

Укажите установленные модификации и проверьте вложения на личные данные перед публикацией.

## Сборка

Windows, Python 3.10+ и PowerShell:

```powershell
./tools/get-toolchain.ps1
python tools/fsd_check.py
python tools/i18n_check.py
python tools/build.py dist
```

Готовый архив: `dist/SA-COOP.zip`. Игровые файлы в него не входят.
