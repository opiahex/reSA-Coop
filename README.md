**reSA-Coop — активная и исправленная версия кооперативного мода для GTA San Andreas, рассчитанная на троих игроков.**

Критические исправления и доработки этого форка:

- Исправлены причины дублирования и исчезновения транспорта при угоне, смене владельца и переходах в интерьер.
- Переработан выбор источника трафика: рядом с хостом используется его зона населения, вдали работают отдельные зоны.
- Исправлены запуск двигателя гостями, конфликт мест в машине и пассажирское место мотоцикла.
- Исправлены передача цветов и вариантов кузова, груза, оборотов винта, колёс, пробитых шин и ремонта.
- Исправлены очереди сюжетных реплик и восстановление экрана, камеры, HUD и управления после сцен.
- Добавлена синхронизация тушения, миссионных предметов, маркеров и их восстановления после потери копии.
- Расширены совместные сюжетные действия, постановочные поездки, попадания, анимации и тихие убийства.
- Устранён ряд причин вылетов при снарядах, удалении занятого транспорта, загрузке мира и переподключении.

## О проекте

reSA-Coop — самостоятельный форк [SA:COOP](https://github.com/Karimov-Akbar/sa-coop).
Его приоритеты — более активное тестирование исправлений, полноценное участие гостей в сюжете и стабильность общего мира втроём.
Оригинальный сюжет, обязательные NPC и логика заданий сохраняются: без дополнительных личных поручений и отдельного интерфейса ролей.

Хост ведёт мир и сюжет из своего сохранения. Два гостя подключаются к нему со своими персонажами, деньгами, оружием и навыками.
Общий мир включает NPC, транспорт, объекты, огонь, сюжетные маркеры и находки. Подработки, школы и спортзал остаются личными занятиями.
Радио каждый выбирает у себя.

Текущая база: **0.2.24-3p, протокол 35**. Это активно дорабатываемый мод: исправления отдельных механизмов не означают, что весь сюжет и любые сторонние моды уже проверены без исключений.

## Установка

1. Установите GTA San Andreas **1.0 US**. Definitive Edition не поддерживается.
2. Откройте [Releases](https://github.com/opiahex/reSA-Coop/releases) и скачайте **reSA-Coop-…-win32.zip** из Assets. Архивы «Source code» предназначены для разработки.
3. Распакуйте архив в каталог с `gta_sa.exe`. Рядом должны появиться `coop.asi`, `install.bat` и папка `coop`.
4. При отсутствии ASI-загрузчика запустите `install.bat`. Он сохраняет оригинальную библиотеку игры как `vorbisHooked.dll`.
5. Запустите игру и откройте меню мода клавишей **F9**.

Обновляться должны **хост, оба гостя и сервер**. Сборки с разными протоколами несовместимы.
При обновлении сохраните настройки и `coop/server-data`: там находятся профили игроков.
`coop.asi` — это игровой мод; отдельный `coop.dll` игрокам устанавливать не требуется.

## Подключение и сюжет

Хост открывает F9 → «Создать игру», выбирает сохранение и создаёт сервер.
Гости открывают F9 → «Подключиться» и вводят код хоста. Встроенный сервер запускается вместе с сеансом; разрешите ему доступ в брандмауэре Windows.
Возможность прямого соединения зависит от сети; параметры подключения и ретранслятора доступны в меню мода.

Сюжет запускает хост. Для важных сюжетных маркеров требуется присутствие подключённых участников; обычные деньги, оружие и аптечки этого не требуют.
Смерть любого участника общей миссии запускает её штатный провал. Положительная награда за выполненную миссию учитывается у каждого участника один раз.
Если сюжетная машина не вмещает всех, поддерживаемые сценарные механизмы предоставляют дополнительный транспорт. Обычное сопровождение остаётся добровольным; стрелковые роли включаются только в соответствующих постановочных эпизодах.

Для воспроизводимого общего мира используйте совместимые сюжетные скрипты, характеристики транспорта и коллизии моделей. Произвольные дополнительные SCM-команды и миссионные модификации могут требовать отдельных адаптаций.

## Сообщить о проблеме

Создайте [issue](https://github.com/opiahex/reSA-Coop/issues), указав версию мода, миссию, кто был хостом, действия до сбоя и список игровых модов.
Приложите `coop/coop.log` и, при вылете, `coop/crash.log`; для рассинхронизации полезны логи всех участников за один сеанс и соответствующие файлы из `coop/diagnostics`.
Перед публикацией удалите личные данные из вложений.

## Сборка из исходников

Нужны Windows, Python 3.10+ и PowerShell. Компилятор загружается скриптом проекта:

```powershell
./tools/get-toolchain.ps1
python tools/fsd_check.py
python tools/i18n_check.py
python tools/build.py dist
```

Результат — `dist/SA-COOP.zip`, готовый к установке. Технические имена `coop.asi`, `coop-server.exe` и папки `coop` сохранены для совместимости.
GitHub Actions собирает проект при изменении `main`; тег `v…` выпускает готовый ZIP и контрольную сумму в GitHub Releases.
Игровые файлы, сохранения и локальные материалы прогонов в репозиторий и архивы не входят.
